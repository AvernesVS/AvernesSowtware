# Проверка AvernesSowtware 1.5.2

- Регрессионные тесты проверяют безопасное освобождение телохранителей, отключение evasive dive для NPC под прицелом, запрет выпадения оружия, усиление Nitro, Fort Zancudo и неблокирующий файловый обработчик завершения CLR.
- Упаковка и статическая проверка не заменяют запуск GTA V Legacy с ScriptHookVDotNet2.
- Native crash stack не может быть подтверждён только managed-логом. Для окончательного подтверждения нужны повторяемый игровой сценарий и crash dump.
- Парашют: автоматическая выдача гаджета исключена, отдельная команда выдаёт его только по запросу. Метод автооткрытия остаётся no-op. Проверить визуальный купол в игре и исключить конфликты других модов.
