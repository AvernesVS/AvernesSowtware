# AvernesSowtware 1.5.2

## Исправления
- Массовое увольнение телохранителей: последовательное безопасное освобождение NPC из группы вместо `Delete()` и `CLEAR_PED_TASKS_IMMEDIATELY`.
- При прицеливании отключается evasive dive только у текущего NPC; при смене/снятии прицела поведение восстанавливается. У NPC, по которому ведётся прицеливание, отключён сброс оружия после смерти.
- У телохранителей также отключён сброс оружия после смерти.
- Nitro: vehicle-level speed cap применяется ко всем классам транспорта; увеличена сила ускорения автомобилей, мотоциклов и авиации.
- Fort Zancudo: локальное подавление армии действует независимо от глобальных настроек розыска; радиус поиска сокращён для снижения нагрузки.
- Завершение CLR: обработчик ProcessExit больше не вызывает файловую ротацию, повторные попытки и `Flush(true)`.
- Парашют исключён из автоматической выдачи полного арсенала; добавлена отдельная ручная выдача по команде меню. Автоматического открытия нет, развёртывание остаётся под управлением игрока.

## Ограничения проверки
- Исходники не содержат активного вызова открытия парашюта: `ProcessAutomaticParachuteDeployment` уже является no-op. Поэтому самопроизвольное раскрытие визуальной модели может быть связано с игровым ресурсом/состоянием или другим модом и требует проверки в GTA V Legacy.
- Нативные игровые эффекты, физика Nitro, Fort Zancudo и завершение процесса требуют игрового прогона. Статические тесты не подтверждают отсутствие native crash.
