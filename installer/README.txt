# Установка AvernesTreiner 0.9.11

1. Распакуйте весь архив в отдельную папку.
2. Запустите INSTALL.bat.
3. Если архив лежит не в папке GTA V Legacy, укажите полный путь к папке с GTA5.exe.
4. Установщик создаст резервную копию и перенесёт существующие Config.ini, SavedVehicles.json, WeaponInventory.json и addons.json в Документы\AvernesTreiner, не перезаписывая уже существующие пользовательские файлы.

## Исправления версии 0.9.11

- Исправлена проверка группы игрока, включая ситуацию, когда игрок не состоит в группе.
- Удалён ошибочный вызов проверки поезда из фильтра целей; добавлена поддержка SWAT при розыске.
- Сканирование NPC ограничено ближайшей областью и выполняется с интервалом 500 мс; перебор пула объектов отключён, проверка мишеней тира использует луч только по объектам. Aim Bot автоматически приостанавливается, пока игрок находится в транспорте.
- Проверка луча по мишеням тира выполняется до полного поиска NPC; исправлено автоматическое обновление чекбокса Aim Bot.
- Немного снижена точка прицеливания по NPC пешком; для тяжёлых промышленных и коммерческих грузовиков добавлена отдельная более высокая точка.

- Aim Bot проверяет объект прямо под прицелом и использует расширенный, но ограниченный список моделей мишеней Ammu-Nation.
- Телохранителям выдаётся отдельная команда пешком подойти и сесть на свободное пассажирское место в транспорте игрока. Телохранитель не телепортируется в машину; боевые задачи не должны прерываться.
- Все журналы, маркеры сессии и диагностические ZIP-отчёты хранятся в `scripts\AvermesBags`. Старые журналы и ZIP-файлы переносятся из прежней папки Documents без перезаписи уже существующих файлов.

## Возможности версии 0.9.7

- Aim Bot игнорирует животных, друзей, телохранителей и участников отряда; для тира добавлена отдельная проверка ограниченного набора объектов-мишеней.
- Повторные записи выбора одной и той же цели ограничиваются.
- Снайпер-телохранитель получает 400 здоровья и 100 брони; для отставших телохранителей поддерживается отдельное следование вне лимита группы GTA.
- Команды арсенала явно переключают оружие и проверяют его наличие у NPC; удаления телохранителей записываются в журнал.
- Диагностика сбрасывает журнал на диск каждую секунду, использует принудительный сброс файлового буфера и закрывает маркер при штатной выгрузке скрипта.
- Нативный жёсткий вылет игры не всегда позволяет выполнить обработчики .NET; частая запись уменьшает возможную потерю последних событий, но не гарантирует stack trace для каждого вылета.

## Новые возможности телохранителей в 0.9.6

- В меню создания одиночного телохранителя добавлен снайпер Black Ops с винтовкой Sniper Rifle.
- В арсенале добавлена команда выдачи снайперских винтовок всем активным телохранителям.
- Для телохранителя со снайперской винтовкой устанавливается точность 95; обычные бойцы сохраняют прежнюю настройку.
- Ошибки создания телохранителей записываются в локальную диагностику.

## Диагностика

Диагностика включена по умолчанию. Журналы сохраняются в GTA V\scripts\AvermesBags\Logs:
- буфер в памяти ограничен 256 событиями;
- запись на диск выполняется раз в 1 секунду и сразу после ошибки;
- текущий журнал ограничен 2 МБ, хранится также одна предыдущая копия;
- повторяющиеся одинаковые исключения ограничиваются по частоте;
- подробное логирование выключено по умолчанию;
- никакие данные автоматически не отправляются в интернет.

В меню трейнера откройте «Диагностика». Там можно отключить диагностику, включить подробное логирование или вручную создать ZIP-отчёт. Архив появится в GTA V\scripts\AvermesBags. Отправляйте его только по своему желанию.

Если GTA завершилась аварийно, файл Session.active может остаться в папке GTA V\scripts\AvermesBags\Logs. При следующем запуске это будет отмечено в журнале. Такой признак показывает некорректное завершение сессии, но сам по себе не доказывает, что виноват именно трейнер.

## Важное для Aim Bot

В 0.9.5 удалён вызов GET_PED_TARGET_FROM_COMBAT_PED (0x32C27A11307B01CC), которого нет в GTA V Legacy build 2245. Также исправлен запрос координат головы NPC. При первом запуске после обновления рекомендуется оставить Aim Bot выключенным, убедиться, что трейнер загружается без критической ошибки, и только затем отдельно проверить Aim Bot.

Для удаления запустите UNINSTALL.bat. Он удаляет только DLL трейнера и штатные локализации; настройки, сохранённые машины, журналы диагностики и сторонние файлы остаются на месте.

Требуются GTA V Legacy 1.0.2245.0, Script Hook V, ScriptHookVDotNet 2.10.13, NativeUI 1.9.0 и .NET Framework 4.8.
