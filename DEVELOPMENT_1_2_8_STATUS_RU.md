# YnixTrainer Extended 1.2.8 — рабочий журнал

## Статус на 13.11.2026
Локальная исходная поставка 1.2.8 собрана в ZIP (42 файла), целостность архива проверена. Проверка структуры и данных завершилась с 0 ошибками и одним предупреждением: в текущем контейнере нет C# compiler/MSBuild/Mono, поэтому DLL не скомпилирована. GTA V runtime-тест не выполнялся.

Работа в GitHub ведётся в отдельной ветке `work/1.2.8-development`; `main` не изменялась. Ветка содержит журнал разработки и архив-основу 1.2.6. Полный исходный ZIP 1.2.8 пока не синхронизирован в репозиторий, поэтому Windows CI workflow не оставлен включённым: запуск сборки без исходников был бы ложной проверкой.

## Подтверждённые результаты тестирования 1.2.7
- Установка и резервное копирование прошли успешно.
- Спавн основных типов транспорта стабилен.
- Неон и тонировка применяются по логам.
- Телепортация с ожиданием GroundZ работает без провалов под карту.
- В пользовательских логах нет строк [ERROR].

## Приоритетные исправления 1.2.8
1. Anti-Eject и удержание персонажа в машине при аварии.
2. Восстановление причёски Franklin после сюжетной cutscene.
3. Деспавн разрушенного транспорта, повторные попытки удаления и защита от переиспользования entity handle.
4. Мотоциклетные колёса: Bike wheel type, front/rear slots и custom tyre variation.
5. Управляемый projectile-режим ракет для поддерживаемых вертолётов.
6. Сброс override парашюта; визуальные текстуры требуют игрового теста.
7. Точность спидометра через GET_ENTITY_SPEED.
8. Настраиваемое Nitro (0.50x–3.00x), ограничение 450 км/ч и отключение при буксировке.
9. Vehicle God Mode для транспорта игрока независимо от источника.
10. Limo tint (index 5).
11. Категории T20 и FBI SUV; FBI SUV — модель fbi2.
12. Удаление отдельной страницы Add-On Vehicles при сохранении addons.json и общего каталога.

## Дополнительный объём
- Модульное разделение монолита с сохранением всех обнаруженных 165/165 старых объявлений методов.
- Atlas: ручной чек-лист по весам 100% структуры, сохранение счётчиков; не читает автоматически save stats и не знает per-item флаги.
- Wardrobe: доступные drawable/texture текущего персонажа, 10 комплектов на модель; отсутствующие DLC не разблокируются.
- BUILD_RELEASE.bat: pre-check, компиляция, post-check, ZIP-пакетирование без автоматической установки.
- Installer/uninstaller сохранены; настройки и пользовательские JSON должны сохраняться.

## Статические проверки
- ZIP: 42 файла, архив открывается без ошибок.
- 7 JSON-файлов синтаксически корректны.
- Два каталога транспорта: по 469 моделей, дубликатов нет.
- T20/fbi2 сверены по категориям.
- Все 6 C# модулей подключены в build script и csproj.
- 165/165 старых распознанных объявлений методов найдены в новой совокупности модулей.
- Баланс C# delimiters проверен статически.
- ReleaseValidator и ReleasePackager подготовлены для выполнения на Windows.

## Что не подтверждено
- Компиляция DLL на Windows/SHVDN2.
- Успешный запуск DLL в GTA V Legacy.
- Фактическое поведение Anti-Eject, Franklin hair, despawn, мото-колёс, вертолётных ракет, парашюта, спидометра и Nitro.
- Реальный 100% статус прохождения из сохранения; Atlas пока ручной.
- Безопасная телепортация к каждому конкретному коллекционному предмету.

## Сохранность
Не удалять старые функции, команды, настройки, данные, меню и installer/uninstaller. Не менять целевую связку C# 4 / .NET Framework 4.0 API / ScriptHookVDotNet2. GTA Online не поддерживается. Не публиковать RELEASE до успешной компиляции и проверки полного ZIP.
