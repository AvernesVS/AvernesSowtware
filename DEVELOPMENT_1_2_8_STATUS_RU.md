# YnixTrainer Extended 1.2.8 — рабочий журнал

## Статус
Разработка начата. Работа ведётся в отдельной ветке `work/1.2.8-development`. Ветка `main` не изменялась. Ветка создана от проверенной GitHub-основы 1.2.6; фактическая пользовательская тестовая база 1.2.7 передана отдельным ZIP в текущей задаче и используется для локальной dev-сборки.

## Подтверждённые результаты тестирования 1.2.7
- Установка и резервное копирование прошли успешно.
- Спавн основных типов транспорта стабилен.
- Неон и тонировка применяются по логам.
- Телепортация с ожиданием GroundZ работает без провалов под карту.
- В пользовательских логах нет строк [ERROR].

## Приоритетные исправления 1.2.8
1. Anti-Eject и сохранение поведения персонажа при аварии.
2. Восстановление прически Franklin после сюжетной cutscene.
3. Деспавн разрушенного транспорта, повторные попытки удаления и защита от переиспользования entity handle.
4. Мотоциклетные колёса: Bike wheel type, front/rear slots и custom tyre variation.
5. Управляемый ракетный режим для поддерживаемых вертолётов.
6. Сброс override парашюта; проверка визуальных текстур остаётся игровой.
7. Точность спидометра по горизонтальной скорости.
8. Настраиваемое Nitro с безопасным потолком, без экстремальных значений.
9. Vehicle God Mode для транспорта игрока независимо от его источника.
10. Limo tint (index 5).
11. Категории T20 и FBI SUV без потери записей каталога.

## Дополнительный объём
- Модульное разделение монолитного класса с сохранением старых сигнатур.
- Раздел Atlas с честным ручным трекером до подтверждения чтения реальных игровых stats/per-item flags.
- Раздел Wardrobe с проверкой доступности drawable/texture и 10 слотами комплектов на модель персонажа.
- Обновление build pipeline: один BUILD_RELEASE.bat, статические проверки, сборка и ZIP без автоматической установки.

## Ограничения проверок
Текущая среда не содержит доступного компилятора C# / MSBuild и запуска GTA V. Поэтому до сборки на целевой Windows и игрового теста версия остаётся DEV. Никакие runtime-исправления не считаются подтверждёнными только по статическому анализу.

## Сохранность
Не удалять старые функции, команды, настройки, данные, меню и installer/uninstaller. Не менять целевую связку C# 4 / .NET Framework 4.0 API / ScriptHookVDotNet2. GTA Online не поддерживается.
