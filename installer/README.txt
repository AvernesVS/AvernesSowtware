# Установка AvernesTreiner 0.8.3

1. Распакуйте весь архив в отдельную папку.
2. Запустите INSTALL.bat.
3. Если архив лежит не в папке GTA V Legacy, укажите полный путь к папке с GTA5.exe.
4. Установщик создаст резервную копию и автоматически перенесёт Config.ini, SavedVehicles.json и addons.json в Документы\AvernesTreiner. Старые резервные копии также обнаруживаются.
5. Трейнер читает и сохраняет пользовательские данные в Документы\AvernesTreiner. Уже существующие файлы не перезаписываются старыми копиями.

Для удаления запустите UNINSTALL.bat. Он удаляет только DLL трейнера и две штатные локализации; настройки, сохранённые машины и сторонние файлы остаются на месте.

Требуются GTA V Legacy, Script Hook V, ScriptHookVDotNet 2.10.13, NativeUI 1.9.0 и .NET Framework 4.8.
