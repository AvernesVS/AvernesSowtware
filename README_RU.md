# AvernesSowtware 1.4.5 — GTA V Legacy Trainer

AvernesSowtware — trainer для GTA V Legacy Story Mode на ScriptHookVDotNet2. Версия 1.4.5 — адресное исправление подтверждённых проблем из игрового тестирования 1.4.2. Существующие меню, функции, настройки, интеграции и пользовательские данные сохраняются.

## Исправления 1.4.5

- **Nitro:** ускорение разрешено только когда игрок занимает водительское место (seat -1). Пассажир не изменяет скорость/handling NPC-управляемого транспорта. После отключения Nitro временные параметры восстанавливаются.
- **Vehicle God Mode:** при первом применении защиты к текущей машине и при повторном включении режима выполняется однократный полный ремонт существующих повреждений. `SET_VEHICLE_FIXED` не вызывается на каждом 250-мс обновлении, чтобы не сбрасывать анимации дверей.
- **Совместимость:** сохранены C# 4, .NET Framework 4.0 API, ScriptHookVDotNet2 API 2, прежние публичные функции, меню и форматы пользовательских данных.

## Открытые пункты — не объявлены исправленными

- Поведение стрельбы телохранителей и массовое удаление требуют отдельного игрового теста.
- Fort Zancudo: полное прекращение появления истребителей не подтверждено.
- Логирование: если скрипт не загружается, managed-лог не создаётся; требуется проверить загрузку SHVDN и оба ожидаемых пути журнала.
- Каталог: в предыдущем тесте отображалось 542 автомобиля; цель 619 не достигнута.
- Повторное использование сохранённого транспорта требует проверки по пользовательскому `saved_vehicles.json`; данные не перезаписываются.

## Установка релиза 1.4.5

1. Закрой GTA V Legacy и распакуй архив, сохранив структуру каталогов.
2. Запусти `Install_AvernesSowtware.bat`.
3. Убедись, что установлен ScriptHookVDotNet2 API 2, затем запусти GTA V Legacy в Story Mode.
4. Перед обновлением сделай резервную копию `scripts\AvernesSowtware`.

Пользовательские настройки, сохранённые машины, избранные точки, hotkeys и дополнения сохраняются. Установщик не должен удалять или обнулять пользовательские данные.

## Исправления 1.3.9

- Nitro масштабируется линейно: x3 соответствует целевому порогу 450 км/ч, x8 — 1200 км/ч. Ускорение остаётся физическим, без покадровой перезаписи абсолютной скорости.
- Vehicle God Mode выполняет полный ремонт только при включении защиты/первом применении к новому автомобилю, а не при каждом 250-мс обновлении. Это устраняет источник сброса анимаций дверей, шасси и состояния наведения.
- Never Wanted дополнительно обрабатывает только ближайших бойцов группы ARMY, которые уже находятся в бою именно с игроком, и только в пределах района Форт-Занкудо. Глобальная блокировка AI и отключение армейского транспорта не используются.
- Для Oppressor Mk II устранён обнаруженный конфликт повторного ремонта; отдельного кода ракетного прицела/захвата в тренере нет, поэтому его фактическая стабильность требует проверки в Story Mode.

## Исправления 1.3.7

- Nitro работает через физическую силу, а не через покадровую перезапись абсолютной скорости.
- Полный ремонт транспорта больше не повторяется при каждом обновлении защиты.
- Для Форт-Занкудо добавлена ограниченная обработка активного боя NPC группы ARMY с игроком.
- Алгоритм ракетного прицела Oppressor Mk II в тренере отсутствует; его поведение требует проверки в игре.

## Обновления 1.3.6

- Исправлен Never Wanted: больше не используется глобальная блокировка AI, не отключается служба армейского транспорта; нейтрализуется только отношение ARMY к игроку.
- Телохранители получают обычный урон от пуль и взрывов; добавлены настройки бессмертия, HP (100–1000) и брони (0–100).
- Посадка телохранителей резервирует пассажирские места, чтобы несколько NPC не выбирали один и тот же слот.
- Добавлены зелёные индивидуальные маркеры телохранителей и автоматическая выдача Micro SMG при прицеливании из машины.
- Восстановлены штатные множители плотности пешеходов, сценарных NPC и транспорта каждый игровой кадр.
- Nitro усилен, прежний предел 450 км/ч поднят до 900 км/ч.
- При включении Vehicle God Mode выполняется ремонт уже имеющихся повреждений, затем повторно фиксируется деформация.



- Добавлен Enus Super Diamond: реальная модель GTA V `superd`; поиск понимает `superd`, `superdiamond`, `Enus Super Diamond`, JOAAT ID `0x42F2ED16` и десятичное значение.
- Добавлена отдельная команда «Максимальный тюнинг» (на базе существующего Max Tuning 1.3.3).
- Добавлена команда «Установить все обвесы»: отсутствующие для конкретной модели слоты пропускаются, каждая деталь обрабатывается отдельно.
- Добавлены меню выбора семейства и стиля колёс, а также отдельных визуальных деталей кузова.
- Удалён Smart Autopilot/Waypoint Autopilot; отдельная безопасная функция телепорта на установленную метку восстановлена.
- Удалены раздел Atlas и меню смены одежды/гардероба. Старые пользовательские JSON-файлы не удаляются автоматически.
- Телохранители периодически восстанавливают выбранное оружие и обычную уязвимость к урону.
- Max Tuning устанавливает жёлто-чёрный номер и максимальную тонировку; для ПВО-прицепа сохраняются штатные колёса.
- Vehicle God Mode повторно применяет защиту и исправляет деформацию; Nitro получил увеличенный диапазон мощности.
- Спавненный транспорт повторно закрепляется как mission entity.

Вызов полицейской машины через штатный 911 не реализован в тренере: этот пункт требует отдельного теста без сторонних модов и с отключёнными Never Wanted/Cops Ignore.

Встроенные JSON содержат 480 основных и 85 дополнительных записей; после дедупликации в исходном пакете 545 уникальных `model`. В 1.4.5 каталог дополнительно проверяет `IsValid`, `IsInCdImage` и `IsVehicle` в установленной сборке Legacy и исключает недоступные модели (например, `lm87` для сборок, где этой модели нет). Целевой счётчик 619 требует подтверждённого полного списка дополнительных моделей; произвольные записи и фиктивные счётчики не добавляются.

## Новые инструменты 1.3.9

- Настройка клавиш: `Settings → Custom hotkeys`; выбери действие и нажми одну клавишу. ESC отменяет назначение, конфликтующая клавиша не принимается.
- Возврат телепорта: `Teleport → Undo last teleport`; сохраняются 10 последних исходных точек.
- Перезагрузка JSON: `Settings → Developer tools → Reload JSON configurations`.
- Профилировщик и watchdog пишут диагностические записи в локальные логи; порог зависания движения — 5 последовательных проверок с интервалом около секунды.

## Совместимость

Игровой runtime GTA V Legacy не запускался.
